# 隐私与安全边界

[English](SECURITY.md) | [简体中文](SECURITY.zh-CN.md) · [漏洞报告](../SECURITY.md)

## 数据归属与隔离

软件源码、私有工作档案、可分享的合成样例是不同对象。真实 auth、会话抓包、笔记、证书、客户端数据库、清单、恢复报告都不应公开。

档案与 vault 可能包含明文笔记和私密元数据。本项目不加密输出 ZIP。没有凭据的 vault 仍属于私有内容。

## 凭据与网络

- 第一方客户端访问配置中允许的 HTTPS 知识库主机及账号服务。
- token 请求头只发往配置中的知识库主机或账号服务，不发给任意资源主机。
- 跳转重新检查；对象存储请求不携带为知 token 请求头。
- 编辑器令牌只在本机内存使用，不写入归档响应。
- 证书密码只用于本机解密，不尝试密码恢复或暴力破解。
- 默认不继承环境代理。第一方与外链代理独立配置，不改系统网络。
- 外链镜像使用干净会话，不携带为知请求头、Cookie、Authorization 或笔记来源 URL。

原始响应可能带短期签名资源 URL，应放在私有档案，不进入 issue 或公开测试样例。阅读元数据会过滤类似凭据的字段，但不承诺匿名化原始正文。

## 本机 HTTP 服务

进度看板绑定回环地址，检查 Host，只暴露固定计数结构，拒绝任意文件系统路径，不提供笔记下载。页面使用本地资源及严格 CSP。

看板不用于公开托管或远程管理。需要远程查看时使用本人控制的转发方案，不随意改成公网监听。

## 不可信档案与资源

安全提取在发布输出前检查路径、类型、大小、数量、同名冲突。符号链接、设备文件、路径穿越、内容冲突的重复成员拒绝处理。逐字节相同的重复成员可提取一次，同时保留原 ZIP。

阅读 HTML 移除主动内容，并用 CSP 阻止自动访问外部资源。应阅读生成副本，不直接打开不可信原始网页。原始内容用于证据与未来转换。

外链镜像检查协议、userinfo、端口、DNS、跳转、MIME/文件签名及资源限额。缓存只能写到缓存目录下的预期 URL 哈希路径，清单不能指定任意原始对象路径。

DNS 校验只是本机预检。HTTP 连接未固定已校验的目标 IP，代理也可能自行解析主机，因此不宣称彻底阻止 DNS rebinding。不可信链接集合可用 `--no-postprocess` 先归档第一方对象，再单独审查可选镜像范围。

## 安全限额

整库快照与单篇包的限额不同。这些是保护措施，不是可用性保证。

| 操作 | 主要限额 |
| --- | --- |
| 整库快照恢复 | 2,000,000 条目；总解压 512 GiB；单条目 16 GiB |
| 单篇提取 | 20,000 条目；总解压 2 GiB；单成员 1 GiB；正文转换 64 MiB |
| 离线重建中的密文解密 | 密文自动解密上限 512 MiB；较大原件保留 locked，已有明文副本可优先使用 |
| 外链镜像 | 5,000 资源；单资源 50 MiB；总下载 2 GiB |
| CSS 发现 | 深度 2；每样式表最多 200 个引用 |

另外执行压缩比例及可用空间检查。触及限额应明确报告 partial/refused，不能静默截断后仍称完整。调整可信大档案限额前，先核对代码和发行说明。

## 完整性不等于身份认证

ZIP CRC 可发现许多意外损坏。本地 SHA-256 检查字节是否仍符合记录。上游 MD5 可能使用旧表示或本身不一致。这些都不能单独认证攻击者提供的档案。

即使重复下载与本机解密证明对象可以恢复，源校验异常仍应保留。不要手工更新预期哈希来去掉告警。

## 写入边界

- 不修改云端正文和权限。
- 明确请求的本机 setup 可通过登录 POST 认证，编辑器 tokens POST 颁发当前已授权访问的凭据，后续正文操作使用 GET。这些认证步骤不上传笔记或改变分享权限。
- 保留本地原件和密文。
- 离线恢复/重建/vault 写入独立目标。
- 校验会写报告；镜像和索引生成会更新阅读副本及对应记录。
- 不含遥测或自动上传资料功能。

安全问题按[报告说明](../SECURITY.md)提交，使用合成复现，不提交真实笔记或凭据。
